# Module reference

The 152 built-in modules, by toolbox category. Inputs and outputs are the ports you wire together; select a module in the app and open the **Help** tab to see its settings and allowed values.

This page is generated from the module registry (`python scripts/gen_module_reference.py`), so it always matches the app.
